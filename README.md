# Складская техника — каталог и подбор

Одностраничный сайт-каталог складской техники с редакционным промышленным визуальным стилем. Основной сценарий: выбрать категорию и параметры, сравнить модели и подготовить текст обращения к поставщику.

## Запуск локально

Нужен Python 3. Из каталога проекта выполни:

```bash
python3 -m http.server 8000
```

Открой `http://localhost:8000`. Остановить сервер: `Ctrl+C`.

## Проверки

```bash
node --test tests/catalog.test.mjs
node --check catalog.mjs
```

Новых пакетов и сборщика нет.

## Что работает

- Фильтры по типу техники, грузоподъёмности, высоте подъёма, приводу, условиям работы и поиску по модели/категории.
- Сравнение до трёх выбранных моделей.
- Форма проверяет имя и контакт, затем собирает локальный текст обращения, который можно скопировать; данные не отправляются и не сохраняются.
- Адаптивный интерфейс, клавиатурный фокус и режим уменьшенной анимации.

## Ограничения первой версии

- Форма не отправляет и не сохраняет данные: она собирает текст обращения, который можно скопировать вручную. Подключения к CRM, почте или другому каналу обработки нет.
- Цены, наличие, сроки поставки и контакты компании не заявлены.
- Изображения техники в карточках — оригинальные схематические SVG, не фотографии конкретных моделей. На первом экране — фотография склада с Pexels, загружаемая напрямую с их CDN.
- Характеристики и комплектации нужно перепроверять у поставщика перед коммерческим использованием. Ссылки на использованные каталоги находятся в раскрывающемся блоке «Источник параметров» каждой карточки; значения условий работы — широкая классификация для подбора, а не гарантия пригодности модели к конкретному объекту.
- Фото склада загружено с Pexels: https://images.pexels.com/photos/4483608/pexels-photo-4483608.jpeg?cs=tinysrgb&w=1600. Перед публичным коммерческим запуском проверь условия использования изображения.

## Структура

- `index.html` — разметка и тексты.
- `styles.css` — оформление и адаптивность.
- `catalog.mjs` — данные, фильтры, сравнение и локальная форма.
- `favicon.svg` — локальный значок сайта.
- Фото первого экрана запрашивается с Pexels CDN по ссылке выше; отдельной локальной копии в репозитории нет.
- `tests/catalog.test.mjs` — тесты логики каталога.
- `QA-REPORT.md` — объём и результаты проверки текущей версии сайта.
