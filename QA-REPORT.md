## Проверки и результат

- `node --test tests/catalog.test.mjs` — **5/5 тестов пройдены**.
- `node --check catalog.mjs` — успешно.
- Статический аудит HTML/CSS: дубли ID — 0; отсутствующие ARIA-ссылки — 0; неразмеченные поля формы — 0; отсутствующие локальные ресурсы — 0; неопределённые CSS-переменные — 0.
- Браузерный сценарий: фильтр по категории с клавиатуры; пустой результат и сброс; сравнение ограничено тремя моделями; диалог закрывается по Escape с возвратом фокуса; ошибки обязательных полей и email показываются; успешная форма меняет только локальный интерфейс. URL не меняется, сетевые ресурсы загружаются только с локального сервера.
- Favicon: `favicon.svg` возвращает HTTP 200 и `image/svg+xml`.
- Контраст ключевых пар: основной текст 12.66:1; пояснение hero 5.50:1; подписи фильтра 5.70:1; граница поля на светлой панели 3.19:1; текст тёмной кнопки 12.17:1; ошибка формы 6.98:1; фокусное кольцо на светлом фоне 12.17:1.

## Не проверялось / вне области

- Реальное произношение интерфейса NVDA, VoiceOver или TalkBack; проверено дерево доступности браузера, но не отдельная программа чтения с экрана.
- Отдельный запуск браузера при zoom 200% и RTL-локализация; страница русскоязычная, проверены ширины вплоть до 320 CSS px.
- Доступность и актуальность внешних страниц поставщиков, юридические условия лицензии фотографии и пригодность конкретных комплектаций для коммерческой эксплуатации. Перед реальным запуском это нужно перепроверить у поставщиков и по лицензии изображения.
- CRM, email, сохранение или отправка заявки и публикация сайта — намеренно не подключались.

**Вердикт:** Approve для локальной портфолио-версии в проверенном объёме; коммерческие данные, права на фото и реальный сценарий заявок остаются вне этой проверки.
